# Математический тест с использованием фикстуры (pytest)

## Описание
Проект содержит функцию для сложения произвольного количества чисел и набор автоматизированных тестов, использующих параметризованную фикстуру `pytest`.

## Структура проекта
- `operations.py` — функция сложения.
- `tests/settingstest.py` — параметризованная фикстура с тестовыми данными.
- `tests/test_math.py` — тесты, использующие фикстуру.

## Требования
- Python 3.8+
- pytest

## Установка и запуск
1. Клонируйте репозиторий и перейдите в директорию проекта.
2. Установите зависимости:
    pip install -r requirements.txt   pytest -v
